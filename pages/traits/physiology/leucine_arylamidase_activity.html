leucine arylamidase activity

traitmech:000143 · CLASS · PROPOSED

A physiological enzyme-activity phenotype in which a cell produces active leucine arylamidase enzymes that hydrolyze leucine arylamide substrates.

Trait evidence (2)

  • DOI:10.1099/ijsem.0.002327
    enzyme detection with an API zym kit was positive for alkaline phosphatase, esterase, leucine arylamidase, valine arylamidase, acid phosphatase

    Jung et al. detected leucine arylamidase in Lactobacillus allii strain WiKim39 with the API ZYM enzyme activity panel.

  • DOI:10.1155/2021/8888641
    According to the API ZYM assays, all three isolates were positive for alkaline phosphatase, leucine aryl amidase, acid phosphatase, and naphthol_AS_BI_phosphohydrolase.

    Mekonnen et al. treated leucine arylamidase as an assayed bacterial exoenzyme phenotype in rapid urease-producing soil isolates.
