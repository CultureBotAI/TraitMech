valine arylamidase activity

traitmech:000144 · CLASS · PROPOSED

A physiological enzyme-activity phenotype in which a cell produces active valine arylamidase enzymes that hydrolyze valine arylamide substrates.

Trait evidence (2)

  • DOI:10.3389/fmicb.2022.1034816
    Positive alkaline phosphatase, cystine arylamidase, esterase(C4), esterase lipase(C8), leucine arylamidase, naphthol-AS-B1-phosphohydrolase, valine arylamidase

    Jiang et al. treated valine arylamidase as an assayed enzyme-activity phenotype in the Geminicoccus harenae type species description.

  • DOI:10.1099/ijsem.0.002327
    enzyme detection with an API zym kit was positive for alkaline phosphatase, esterase, leucine arylamidase, valine arylamidase, acid phosphatase

    Jung et al. detected valine arylamidase in Lactobacillus allii strain WiKim39 with the API ZYM enzyme activity panel.
