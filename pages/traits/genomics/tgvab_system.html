TgvAB system

traitmech:000412 · CLASS · PROPOSED

A restriction-modification system in which an organism possesses a two-gene TgvAB locus embedded in the Vibrio cholerae VPI-2 type I R-M cluster, encoding TgvA and TgvB modification-dependent restriction proteins related to GmrSD type IV restriction enzymes that restrict glucosylated hmC-containing T-even-like phage DNA.

TgvAB restricts glucosylated T-even-like phage DNA

Conservative system-level sketch linking a two-gene TgvAB locus to modification-dependent type IV restriction of glucosylated hmC-containing T-even-like phage DNA and TgvAB system possession.

NONMECHANISTIC · The graph captures TgvAB at VPI-2, T-even-like-phage, and type-IV-restriction level without asserting complete native host breadth, exact TgvA/TgvB subunit stoichiometry, or a DefenseFinder rule-level profile combination.
