type III restriction-modification system

traitmech:000495 · CLASS · PROPOSED

A restriction-modification system in which an organism possesses a Type III R-M locus encoding Mod-like DNA methyltransferase and Res-like ATP-dependent restriction subunits, including RM_Type_III loci represented by DefenseFinder.

Type III R-M loci mark self and restrict foreign DNA

Conservative system-level sketch linking Type III restriction-modification loci to restriction-modification-mediated foreign DNA cleavage.

NONMECHANISTIC · The graph captures a reusable Type III R-M locus architecture and the DefenseFinder RM_Type_III custom-profile namespace without asserting an accession-level mapping between any custom HMM row and characterized Res or Mod families.
