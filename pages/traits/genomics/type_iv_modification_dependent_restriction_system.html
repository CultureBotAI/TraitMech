type IV modification-dependent restriction system

traitmech:000496 · CLASS · PROPOSED

A phage defense system in which an organism possesses a Type IV modification-dependent restriction locus, including DefenseFinder RM_Type_IV loci, whose restriction-enzyme activity cleaves foreign DNA carrying recognized base or backbone modifications rather than the unmodified targets of canonical Type I-III restriction-modification systems.

Type IV restriction loci attack modified foreign DNA
