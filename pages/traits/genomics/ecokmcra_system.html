EcoKMcrA system

traitmech:000509 · CLASS · PROPOSED

A type IV modification-dependent restriction system in which an organism possesses an EcoKMcrA mcrA locus encoding a methylcytosine- and hydroxymethylcytosine-dependent restriction endonuclease whose nuclease active site is required for efficient restriction of DNA modified in the correct sequence context.

EcoKMcrA restricts modified-cytosine DNA

Conservative system-level sketch linking an EcoKMcrA mcrA locus to modified-cytosine DNA restriction and to the Type IV restriction parent trait.
