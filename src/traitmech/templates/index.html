About

One YAML per record under data/traits/<category>/<slug>.yaml; each carries a stable METPO:<id> identifier, label, definition, parent traits, synonyms, and an optional curation history. See the GitHub repo for the LinkML schema and seeder.

Embedding integration: each page links to the kg-microbe deepwalk embedding for the matching trait node, when one exists. Coverage is currently {{ embedding_coverage_pct }}% — kg-microbe's 2024-09-25 release predates METPO ingestion, so direct CURIE lookup returns nothing and we fall back to label-match through metpo_alias_mappings.tsv plus normalised-label matching against kg-microbe's pre-METPO trait nodes (cell_shape:bacillus, oxygen:aerobe, etc.).
