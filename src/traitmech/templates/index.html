About

One YAML per record under data/traits/<category>/<slug>.yaml; each carries a stable METPO:<id> identifier, label, definition, parent traits, synonyms, and an optional curation history. See the GitHub repo for the LinkML schema and seeder.

Embedding integration: each page links to the kg-microbe deepwalk embedding for the matching trait, with the top 8 nearest neighbors by cosine similarity. Coverage is currently {{ embedding_coverage_pct }}% — sourced from kg-microbe's 2026-04-25 deepwalk (512-D, the first to ingest METPO directly). The 8 unmatched records are all DatatypeProperties that the graph encodes as edge attributes rather than entity nodes.

The embedding-space scatter projects all {{ embedded_count }} matched traits into 2-D via UMAP, coloured by category and searchable by label or CURIE.
